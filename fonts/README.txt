Self-hosted fonts for jhineslaw.com
===================================

These fonts are served from /fonts on this site so the pages do not make
third-party requests (see privacy.html: the site does not use third-party
scripts or trackers). Do not switch these @font-face rules to Google Fonts
or another hosted font CDN.

- Gelasio (variable, normal and italic), SIL Open Font License 1.1.
  Copyright 2019 The Gelasio Project Authors.
  License: OFL-Gelasio.txt

- Inter (variable, normal and italic), SIL Open Font License 1.1.
  Copyright 2016 The Inter Project Authors.
  License: OFL-Inter.txt

Source files were subset to Latin and common punctuation and converted to
WOFF2 from the Google Fonts desktop files already on this machine.
